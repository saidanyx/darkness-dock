# Информация по Анкетам

### Формат подачи:

```
1. Имя (необязательно)
2. Возраст (необязательно)
3. Игровой никнейм
4. Откуда узнали о проекте
```

### Критерии одобрения:

{% hint style="info" %}
* Корректное выполнение пунктов 3 и 4.
* Соответствие с шаблоном анкеты.
{% endhint %}

{% hint style="success" %}

Рекомендуем ознакомиться с информацией о проекте в <#1436663091315085423>.
{% endhint %}

{% endhint %}
